# Khuôn phân tích (Lượt 1 — chưa viết nội dung)

Theo đúng danh sách của First Prompt (Bước 3, Lượt 1). Ngắn gọn, dạng bảng/gạch đầu dòng. Mục nào
thẻ đã tính thì chép từ thẻ, không giải thích lại. Mọi dòng BLOCK/CHECK của thẻ phải xuất hiện.

```markdown
# Phân tích STT {stt} · {Product Name}

1. **Loại sản phẩm / outline:** {loại} → Outline {A|B|C|D}
2. **Conflict File (2) ↔ THÔNG TIN TỪ BRAND**
   | Trường | File (2) | Hãng | Chọn |
   | --- | --- | --- | --- |
   Kiểm bắt buộc — A/B/C: tên chuẩn + năm (2009/2018), level, size & chiều dài, màu, vùng bảo vệ,
   tương thích air vest/body protector, bình CO₂ có kèm không. D: sản phẩm & size tương thích,
   thông số (dung tích, bayonet/screw, kích thước), số lượng trong gói, chứng nhận.
   **Chỉ có trong File (2), sẽ bỏ:** …
3. **H2 bị loại vì thiếu dữ liệu:** … (lý do)
4. **About:** phiên bản {B1…} · {Role}: "{…}" · (phụ kiện: phục vụ {loại} → bộ {A|B|K})
5. **Brand background / URL brand:** đủ | TRỐNG → dừng | không có URL
6. **Sản phẩm gần giống (9 STT trước):** STT … — Differentiator & focus của cả hai; focus trùng: có/không
7. **Other features hợp lệ:** theo thứ tự ưu tiên (nguồn: câu của hãng) → quyết định:
   không hiển thị / chỉ bullet / bullet + H2 Other Highlights (Outline D: tối đa chỉ bullet)

**Cần bạn quyết:** … | "Không có — gõ: Tạo nội dung"
```
