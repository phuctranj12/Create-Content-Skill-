# BÁO CÁO ĐỐI CHIẾU (Giai đoạn 1 — chưa viết bài)

Template: [tên], theo Product type trong FILE (2): [khớp / không khớp với thông tin brand].

## Mục 1. Bảng dữ liệu sẽ dùng

| Tiêu chí | Giá trị | Nguồn | H2 |
| --- | --- | --- | --- |
| Type | <dáng mũ, adjustable?> | Brand | Short (Type) |
| … theo nhãn Key features rồi các ý Long description … | | | |
| Colour | <đúng cột màu File (2)> | File (2) | Design details |
| Size | <câu Size gợi ý trên thẻ> | File (2) (+ brand quy đổi UK) | Sizing & fit |

Tiêu chuẩn ghi như brand ghi, kèm dòng B1 và quality mark: `PAS 015: 2011 (B1: PAS 015:2011), quality mark: Kitemark`.
Mỗi thông tin đúng một H2 (H2 ownership trong `template.md`).

## Mục 2. Conflict
Brand ↔ File (2): giá trị mỗi bên → giá trị dùng (luật chung §1: màu/size theo File (2)).

## Mục 3. Sẽ bỏ
Chỉ có ở File (2) mà brand không có; mục optional không dữ liệu.

## Mục 4. Cần xử lý trước khi viết
Lấy từ các dòng **BLOCK/CHECK** trên thẻ + danh sách Mục 4 trong First prompt.

## Cuối báo cáo
- DE variant: [X], theo quy tắc số [Y] (thẻ đã tính).
- Tổ chức thi đấu sẽ nêu (B2, chỉ Riding Hat).
- Internal link: anchor · URL · vị trí (thẻ đã liệt kê, gồm link trang chủ ở đoạn About).
- Duplicate Risk: sản phẩm liên quan đã viết (thư mục output) + Writing focus.
- Brand paragraph: fact sẽ dùng + cách mở đầu, so với brand paragraph cùng brand đã viết.
