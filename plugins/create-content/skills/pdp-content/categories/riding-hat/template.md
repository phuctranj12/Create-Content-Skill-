# Riding hat category: PDP content template

This file describes the structure of each product page. Rules on sources, accuracy, links, duplicates and choosing the template are in the First prompt.
The file has two parts:
Template chung (common template): blocks that are the same for every product type.
Template riêng (type templates): one complete template per product type (Riding Hat, Hat Silks & Covers, Liners & Parts, Helmet Accessories), in page order. Blocks marked "→ Template chung [section]" follow the common template; all other blocks are described in full.
Labels used in this file:
(always included): the block or bullet is always on the page.
(optional): the block or bullet is left out when the product has no information for it.

# TEMPLATE CHUNG

### C1. H1

Format: [Brand] [Product name] [type word]. The type word is set in each type template.
Brand and product name written exactly as the brand writes them, e.g. "uvex exxential III".
The type word appears once. If the product name already contains it, it is not added again.
No sizes, colours or audience labels unless they are part of the product name. No retailer name.

### C2. Meta title

Format: [Brand] [Product name] [type word] | Discount Equestrian
The suffix " | Discount Equestrian" is 22 characters, used in the meta title only.
Length: up to 60 characters including the suffix. If longer, the suffix is dropped.

### C3. Meta Description

Length: 140 to 155 characters.
Structure: what the product is (type), then one or two features, then optionally one retailer fact (free UK delivery over £45 or 30-day returns).
Example to follow (Rhinegold Pro): title "Rhinegold Pro Riding Hat | Discount Equestrian" (46 characters); description "The Rhinegold Pro Riding Hat is vented, with a soft feel harness, removable washable liner, red release clip and the British Kitemark to PAS 015 2011." (150 characters).
Example to avoid (Charles Owen AYR8 Suede): title of 82 characters and a generic description of 238 characters ("...shop here."), both too long and not specific to the hat.
Length limits are common SEO conventions, not DE-specific research. Adjust them if the SEO team has its own guideline.

### C4. Short description: structure

Purpose: Help shoppers quickly understand what the product is, who it is for and the main value it offers.
No heading. Three parts, in this order:
Opening paragraph: one or two sentences. The frame is set in each type template.
Key features: bullets, each in the format Label: spec, benefit. The first bullet is always Type. The labels and their order are set in each type template.
Navigation bridge: one or two short sentences (no bullets) naming the H2 sections below that match the benefits above. The frame is set in each type template.
Principle: Focus on benefits and outcomes, with only enough feature terminology to help shoppers understand what they can explore below.

### C5. Long description: format

Purpose: Help shoppers understand and verify the product through its specific features and technical details.
Each major section is an H2, not numbered, in the order set in each type template.
Sub-groups inside a section are H3.
Items are short paragraphs that open with a bold label, e.g. "Ventilation: ...", unless the type template says bullets.
Sentence limits are given in brackets next to each item.
Each type template has an H2 ownership list showing which information belongs to which H2.

### C6. Care & maintenance: general

Max ~80 words in total.
When a shared care guide exists ("Shared care guide" = Y), the section is one sentence linking to the guide (Appendix A4), plus any item the type template marks (always included).

### C7. About the brand

Last H2 of every page. Two paragraphs, no H3:
Brand paragraph (40 to 60 words): about the brand, written from the brand information in File (2). It ends on what the brand is known for, so the discount-equestrian.co.uk paragraph follows on naturally. The brand name at its first mention links to the brand page (Appendix A3).
discount-equestrian.co.uk paragraph (about 50 to 60 words): from Appendix C. It opens by linking the brand to discount-equestrian.co.uk as the retailer, so it reads as a continuation of the brand paragraph.

## Appendix B: Safety standards (Riding Hat only)

Last checked: 05/10/2026

### B1. What each standard means

PAS 015:2011: The British specification for equestrian helmets, developed by the British Standards Institution (BSI). It tests flat impact, hazard edge impact, penetration and crush resistance, as well as harness retention and stability. (Source: DE safety standards blog)
VG1 01.040 2014-12: A European interim specification introduced in 2014. It is being progressively replaced by BS EN 1384:2023. (Source: DE safety standards blog)
BS EN 1384:2023: The new harmonised European standard for riding helmets, introduced to replace VG1. It tests flat impact, hazard edge impact, penetration and crush resistance. (Source: DE safety standards blog)
ASTM F1163 (2015 or 2023): The American standard for equestrian helmets, written by ASTM International. The Safety Equipment Institute (SEI) carries out the testing and audits manufacturers. (Source: DE safety standards blog)
SNELL E2016 / E2021: The equestrian helmet standard set by the Snell Memorial Foundation in the United States. Snell certification is voluntary. (Source: DE safety standards blog)
BSI Kitemark (quality mark): Shows the manufacturer's production is audited by BSI on an ongoing basis. One hat from every batch of 800 to 3,200 is independently tested, and a batch that fails is destroyed. (Sources: DE safety standards blog; Charles Owen standards page)
SEI mark (quality mark): Shows the Safety Equipment Institute audits the manufacturer and batch-tests production to confirm it continues to meet the ASTM standard. (Source: DE safety standards blog)
Inspec IC mark (quality mark): Operated by Inspec International. It performs the same ongoing audit and batch-testing role as the Kitemark for European standards. (Source: DE safety standards blog)

### B2. Which governing bodies accept which standards (2026)
