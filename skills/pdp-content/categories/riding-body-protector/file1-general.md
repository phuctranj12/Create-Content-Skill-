# File (1) – Riding Body Protector PDP Format

## Step 0 – Identify the product type

Read the **Product Type** column in File (2) for this product and use the matching outline:

- **Body protector** → Outline A
- **Back protector** → Outline B
- **Air vest** → Outline C
- **Accessory** → Outline D

If the type is missing or unclear, **stop and ask the writer**. Do not guess.

## General rules (all outlines)

- Use only information from THÔNG TIN TỪ BRAND and File (2), following the source rules in the First Prompt. Never invent product features.
- If there is no information for a point, remove that point. If an H2 has no information, remove the H2.
- Each H2 expands on the Short description and follows the **Section ownership rule** below.
- Put material and construction details only in the H2 they explain (e.g. segmented foam → Freedom of Movement; mesh lining → Breathability). Do not create a separate materials section.
- Use every H2 name exactly as written in this file. Only replace [Brand] in the About H2.
- **Do not include general measuring instructions** (how to measure chest, over-shoulder or back length). They repeat across products and add no product-specific value.
- **Short description bullets:** write every feature bullet as **"Label: value"**. The value after the colon must be short, clear and complete: a phrase, not a full sentence (about 4–12 words). No marketing filler, no repeated words from the label. *Example:* "Freedom of movement: Over 120 individually hinged segments"
- Place links only in the Short description and in the About section, following Appendix 1.
- Other features follow the **Other features rule** below.
- No FAQs.

## Section ownership rule

- Each H2 talks only about its own topic. Do not mention, repeat or refer to information that belongs to another H2.
- Do not use cross-references such as "as mentioned above", "see below" or "in addition to its breathable design".
- Each piece of information has one home only.

**Outlines A, B and C**

| Information | Only in |
| --- | --- |
| Standard, level, protected areas, limitation notice, inflation system and speed | Safety Standards & Protection Level |
| Riding activities, competition use, governing body sentence | Riding Use Cases |
| Compatibility with an air vest (Body protector) | Air Vest Compatibility |
| What is included, CO₂ canister, need for a body protector (Air vest) | What You Need |
| Sizes, lengths, size chart, adjustment points, fitting help | Sizing & Fit |
| Panel construction, flexibility, movement | Freedom of Movement |
| Weight, slimness, wearing under a show jacket | Weight & Profile |
| Mesh, lining, ventilation, water resistance | Breathability |
| Fastening, putting it on alone, how to use, what to do after inflation | Ease of Use |
| Features that fit nowhere else | Other Highlights |
| Colour names and style notes | Colours |
| Lifespan, care, inspection, replacement, servicing, warranty | Durability, Care & Replacement |
| Brand and retailer information | About |

**Outline D (Accessory)**

| Information | Only in |
| --- | --- |
| Compatible products, models and sizes | Compatibility |
| Function in the protection system; safety standard and level, if any | What It Does |
| Capacity, fitting type, dimensions, material | Specifications |
| How to attach, fit or replace; when it needs replacing | How to Fit or Use |
| Items in the pack | What's Included |
| Colour names | Colours |
| Care instructions | Care |
| Brand and retailer information | About |

- **Exceptions:**
  - The Short description summarises the key points by design. Its bullets may cover topics that the Long description expands on, but must not copy Long sentences word for word.
  - Product name, Differentiator (in Meta Description and intro) and the fixed governing body sentence may appear where the rules require them.

## Other features rule (all outlines)

**1. What counts as an other feature**

A feature counts as an other feature only if it meets **all three** conditions:

- It is stated in THÔNG TIN TỪ BRAND.
- It does **not** belong to any other H2 under the Section ownership rule. For example, water resistance on an air vest belongs to Breathability, and colours belong to Colours, so neither is an other feature.
- It gives the rider a practical benefit. Generic marketing phrases (e.g. "premium quality", "stylish design") do not count.

**Examples by type** (use only if the brand states them):

| Type | Possible other features |
| --- | --- |
| Body protector | Shoulder protector attachment, reflective details, made-to-measure option, body support |
| Back protector | Zipped pockets, reflective details, gilet style worn as an outer layer |
| Air vest | Compatible outer jackets, reflective details |
| Accessory | Reflective details, custom design option |

**2. Priority order**

- Safety or visibility (e.g. reflective details)
- Fit support or extended protection (e.g. shoulder protector attachment, made-to-measure option)
- Convenience (e.g. zipped pockets)

**3. Display rule**

| Number of valid other features | Short description | Long description |
| --- | --- | --- |
| **0** | No other feature bullet | No Other Highlights H2 |
| **1** | One bullet for that feature | No H2 |
| **2 or more** | One bullet for the highest-priority feature | Outlines A–C: create the **Other Highlights** H2, one paragraph per feature, in priority order. Outline D: no Other Highlights H2; show only the bullet |

Do not repeat the Short bullet word for word in the H2. In the H2, explain the feature in more detail (how it works and its benefit).

## Meta Description

Write one meta description of about 150–160 characters.

**Outlines A, B and C** must include:

- Brand and product name
- Product type: body protector, back protector or air vest
- Certification and level (e.g. BETA 2018 Level 3, EN 1621-2 Level 1, NF S72-800)
- Who it is for, if the product is specific: adults, young riders, children or women
- The Differentiator from File (2), if it is not "/"
- One key highlight from the brand information (e.g. lightweight, flexible, breathable)
- Type-specific requirement:
  - **Back protector:** make clear it protects the back only
  - **Air vest:** state whether a CO₂ canister is included, if known

**Outline D (Accessory)** must include:

- Brand and product name
- Accessory type (e.g. CO₂ canister, body protector cover)
- Compatible product or system, *if the brand confirms it*
- The Differentiator from File (2), if it is not "/"
- One key specification (e.g. 60cc, bayonet fitting)

Do not add any feature that is not in THÔNG TIN TỪ BRAND or File (2).

## Brand rule (all outlines)

- Use **only** the information in the **Brand background** column of File (2) for this product. Do not research or add anything else.
- If the Brand background cell is empty, **stop and tell the writer**.
- Link the brand name on first mention to the URL in the DE Brand URL column of File (2), or Appendix 1. If neither has a URL, ask the writer.
- **End the brand paragraph with a sentence that connects the brand to this product** (e.g. "…so the Motion3 is made in the UK."). This leads naturally into the discount-equestrian.co.uk paragraph.
- **No repetition within 10 consecutive products:** before writing, check the brand paragraphs of the previous 9 products in this thread. For the same brand, do not reuse any identical sentence, and rotate the opening fact by STT (STT 1 → history, STT 2 → where it is made, STT 3 → technology, then repeat).

- Use the chosen version from Appendix 2. Replace only **[Product]** and **{Role}**. Do not change any other wording.
- The paragraph always opens by presenting discount-equestrian.co.uk as the supplier of this product.
- Fill **{Role}** according to the brand:

- Do not link the product name to its own page.
- Use only the URLs below or in File (2). Do not create or guess URLs.
